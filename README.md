# DownGrader

Апгрейд скинов на игровую валюту. Чисто фронтенд, без сервера: все данные (аккаунты, балансы, инвентари, роли) хранятся в `localStorage` браузера.

## Запуск

Node.js и `npm install` не нужны. Открой `index.html` двойным кликом или через Live Server в VS Code. Подойдёт любой статический хостинг (GitHub Pages, Netlify и т.п.).

Интернет нужен для картинок скинов, редкостей и курса валют. Без него сайт работает, просто с заглушками и запасным курсом.

## Структура

```
index.html   разметка
style.css    стили
data.js      база скинов, правила игры, логин и пароль первого админа
storage.js   «база» в localStorage + игровая логика (раньше был сервер)
app.js       интерфейс
```

## Как это работает

- Всё лежит под ключом `downgrader_db_v1`. Посмотреть: DevTools → Application → Local Storage.
- `storage.js` даёт `Store.call(путь, тело)`, тот же набор действий, что был у API: вход, регистрация, фарм, улучшения, покупка, продажа, апгрейд, пополнение, профиль, сброс, админка.
- Пароли хранятся хешем (PBKDF2 с солью), а не открытым текстом.
- Сессия живёт 7 дней и переживает перезагрузку страницы.
- Несколько вкладок синхронизируются через событие `storage`.

## Админ

При первом запуске создаётся админ из `data.js` (`ADMIN_LOGIN`, `ADMIN_PASSWORD`). Если пароль пустой или короче 8 символов, он генерируется и показывается один раз в окне при загрузке. Свой пароль задай в `data.js` до первого запуска.

Забыл пароль или нужно назначить админа: открой консоль браузера (F12) и выполни
```
Store.setAdmin("логин", "новый пароль")
```
Данные игроков при этом не теряются.

## Важно знать

- Данные есть только в том браузере, где ты играл. На другом устройстве или в другом браузере будет чистая база. Если очистить данные сайта, всё пропадёт.
- Защиты от читеров больше нет: любой может поправить `localStorage` в DevTools. Для шуточного некоммерческого проекта это нормально, но роли админа и «автоматический залет» защищены только интерфейсом.
- Аккаунты из старой серверной версии (SQLite) не переносятся: регистрируйтесь заново.
- Пополнение демонстрационное, любой игрок может пополнять баланс до 1 000 000 ₸ за раз без оплаты.
- Если сломал базу, удали ключ `downgrader_db_v1` в Local Storage и перезагрузи страницу.
